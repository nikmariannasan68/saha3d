# САХА 3D — Живая карта Якутии · v0.5

Интерактивный 3D-атлас Республики Саха (Якутия) на CesiumJS. Работают глобус, кинематографичный перелёт, реальные границы улусов и наслегов из OpenStreetMap, слои, поиск, инфопанели, измерения и виртуальные полёты.

## Открыть онлайн

https://nikmariannasan68.github.io/saha3d/

## Быстрый запуск на своём компьютере (Windows)

1. Распакуйте архив в любую папку.
2. Дважды щёлкните **start-saha3d.bat**. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
3. Атлас откроется в браузере по адресу http://localhost:8765. Чёрное окно сервера не закрывайте, пока работаете с атласом.

Почему нельзя просто открыть `index.html`: в режиме `file://` браузер запрещает Web Workers, а без них CesiumJS не рисует поверхность Земли, границы и заливку. Нужен локальный веб-сервер. Его роль выполняет `server.ps1`: это встроенный PowerShell, ставить ничего не нужно.

Для разработчиков на любой ОС: `npx serve .` или `python -m http.server 8080`.

Нужен интернет: библиотеки, тайлы и геоданные загружаются онлайн. Первая загрузка границ из OSM занимает 10–40 секунд, потом данные кэшируются в браузере на 14 дней.

## Архитектура

Сейчас это один файл без сборки (`index.html`). Так его можно запустить где угодно, а пока в рабочей среде нет npm. Код разбит на модули, которые один к одному переходят в целевой проект на React + TS:

```
saha3d-app/                      (целевая структура: Vite + React + TS + Tailwind + Zustand)
├─ src/
│  ├─ app/              App.tsx, store.ts (Zustand: phase, selection, layers, lang)
│  ├─ globe/            EarthGlobe.tsx (Viewer), CameraController.ts, IntroJourney.ts
│  ├─ layers/           LayerManager.ts, DistrictLayer.ts, NaslegLayer.ts, RiversLayer.ts,
│  │                    LakesLayer.ts, TerrainLayer.ts, SatelliteLayer.ts (basemaps), TourismLayer.ts
│  ├─ data/             api.ts (Overpass/Nominatim/NE), wikidata.ts, cache.ts (IndexedDB), models.ts
│  ├─ ui/               SearchPanel, DistrictInfoPanel, ObjectInfoPanel, MapControls, Breadcrumbs,
│  │                    LanguageSwitcher, TimelineControl, Toast, SettingsModal
│  ├─ tools/            MeasurementTools.ts, Profile.tsx
│  ├─ flight/           VirtualFlight.ts
│  └─ edu/              EducationMode.tsx (викторины, сравнение)
server/                          (Node.js + PostgreSQL/PostGIS)
├─ etl/                импорт OSM-выгрузки Якутии (osm2pgsql), Natural Earth, проверка геометрии
├─ api/                /districts, /naslegs?district=, /search?q=, /objects/:id (GeoJSON)
└─ tiles/              векторные тайлы (pg_tileserv / Martin) для больших слоёв
```

Соответствие разделов в `index.html`: `0 Utils/Store` → store, `1 EarthGlobe`, `2 Basemaps/Terrain`, `3 DataService`, `4 DistrictLayer/NaslegLayer`, `5 Rivers/Lakes`, `6 Selection & InfoPanels`, `7 SearchPanel`, `8 CameraController/VirtualFlight`, `9 MeasurementTools`, `10 UI wiring`.

**Модели данных** (в целевом проекте это `models.ts`):
- `District {id: osmRelId, tags, geometry, bbox, area, centre: Place, places[]}`
- `Nasleg {id, parent: districtId, tags, geometry, area, places[]}`
- `Place {id: osmNodeId, lon, lat, tags.place, population, centre: bool, d: districtId}`
- `River {id, name, qid, lines[][], rank}`, `Lake {id, name, qid, geometry, area}`
- `Object3D {id, lon, lat, height, model: url.glb, schematic: bool, source}` — следующий этап

**Память и производительность.** Каждый слой лежит в своём `CustomDataSource`. При смене улуса наслеги удаляются (`removeAll`), при смене подложки слои уничтожаются (`removeAll(true)`). Границы упрощены на сервере Nominatim (`polygon_threshold`). Тяжёлые слои (реки, озёра, наслеги) грузятся только по запросу. Наведение ограничено частотой ~14 Гц.

## Публикация сайта

Сайт опубликован на **GitHub Pages**: https://nikmariannasan68.github.io/saha3d/ — репозиторий https://github.com/nikmariannasan68/saha3d

Как устроено:
- Это статический сайт: `index.html` + папка `data/` со **снимком геоданных** (границы, наслеги, населённые пункты, тематические слои, реки, озёра). Сайт сначала читает снимок и потому открывается быстро, а серверы OpenStreetMap (Overpass, Nominatim) использует только как запасной вариант. Дата снимка показана внизу справа.
- Спутниковые подложки, 3D-рельеф, NASA GIBS, прогноз сияния NOAA и Wikidata загружаются из браузера посетителя напрямую, ключи не нужны.
- `.nojekyll` отключает обработку Jekyll на GitHub Pages.
- `start-saha3d.bat` и `server.ps1` нужны только для локального запуска и сборки снимка, на сайте они ни на что не влияют.

### Обновление снимка геоданных
1. Запустите `start-saha3d.bat` (атлас откроется на http://localhost:8765).
2. Откройте консоль браузера (F12 → Console) и выполните `SAHA.exportSnapshot()` — все данные заново скачаются из OSM и сохранятся в папку `data/` (20–40 минут).
3. Загрузите изменённые файлы в репозиторий — сайт обновится через 1–2 минуты.

### Другие хостинги
Подойдёт любой статический хостинг: Netlify / Cloudflare Pages (перетащить папку), российские Beget, Timeweb, Yandex Object Storage (статический сайт из бакета), свой nginx. Нужно выложить `index.html`, `.nojekyll` и папку `data/`.

Перед массовым запуском:
1. Для большой посещаемости — свой сервер данных (PostGIS + векторные тайлы) вместо снимка JSON и запасного Overpass.
2. Спутниковая подложка Esri из России может быть недоступна: атлас сам переключается на OSM/CARTO; для продакшена в РФ лучше собственные тайлы.
3. На странице видна атрибуция OSM (ODbL), Natural Earth, Wikidata (CC0), Википедии (CC BY-SA), NASA GIBS, NOAA SWPC, Terrain Tiles и Cesium.
4. Сверить административное деление с официальным реестром Якутии — OSM открытый, но не юридический источник.
